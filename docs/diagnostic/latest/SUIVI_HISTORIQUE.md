# Suivi des problèmes historiques

Le premier diagnostic a 43 identifiants. Le [rapport r03](../../../archives/r03/RAPPORT_AMELIORATIONS_R03.md#registre-des-corrections) les reprend individuellement. Le tableau utilise les gravités d’origine pour comparer une même cohorte. Les lignes suivantes isolent les points nouveaux des rapports r03, r04, r05 et des deux revues V5. Un ancien sous-ensemble peut devenir non applicable alors que sa fonction générale reste à qualifier sur la V5.
